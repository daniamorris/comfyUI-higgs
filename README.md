# comfyUI-higgs
My submission
 for the open Source Higgsfield ComfyUI Hack

Vibe check is a text to video generator that asks you how you're feeling and generates a video with sound in response - using Flux 3 by Black Forest Labs and Anthropic Claude (Sonnet 5.5)

To run this ComfyUI workflow simply drag the json file into your local comfy desktop or cloud account. You can also click this link to get there:
https://cloud.comfy.org/?share=5fbabcf67967

Additional model and node info is included in the workflow but defaults to app mode so anyone can run it!
